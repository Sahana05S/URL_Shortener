# Evidence

The screenshots in this directory use deterministic fixture data and verify
the rendered UI before deployment. Regenerate them with:

```bash
npm run evidence:capture
```

Before submission, replace or supplement them with screenshots from the final
Render deployment and add a sanitized `demo-output.md` containing real demo
logs and representative database rows. Never include credentials, password
hashes, session hashes, visitor hashes, cookies, or raw environment values.
